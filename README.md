# Gorodovoi Wake Word Dataset

Russian audio dataset for wake-word / keyword-spotting models using the wake word **«Городовой»**.

## Structure

```text
positive/   # Wake-word recordings
negative/   # Non-wake-word / background recordings
```

### Dataset

- **778 positive samples**
- **Duration:** 1.0 s per sample
- **Sample rate:** 16 kHz
- **Channels:** Mono
- **Format:** WAV, 16-bit PCM
- **Positive audio:** `positive/`
- **Negative audio:** `negative/` *(not added yet)*
